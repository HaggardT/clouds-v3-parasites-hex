# Clouds v3 Parasites hex for Dual Crystal DIY boards

Модификация альтернативной прошивки **Parasites** (v3) для Eurorack-модуля **Mutable Instruments Clouds**, адаптированная специально для DIY-версий плат с **двумя кварцевыми резонаторами** (Dual Crystal).

## 📁 Структура репозитория
* `firmware/original-parasites/` — оригинальный исходный код прошивки (Matthias Puech).
* `ready-to-flash/` — готовые скомпилированные `.hex` и `.wav` файлы для быстрой заливки в модуль.
* `docs/` — инструкции по прошивке программатором ST-Link и шпаргалки по режимам.

## 💾 Как прошить
Подробное руководство по прошивке находится в файле [docs/flashing_guide_ru.md](docs/flashing_guide_ru.md).
