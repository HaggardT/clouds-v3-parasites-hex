# Инструкция по прошивке Clouds DIY через UART (USB-TTL адаптер)

В данном руководстве описан процесс заливки модифицированной прошивки Parasites в плату Eurorack-модуля Mutable Instruments Clouds по схеме с двумя резонаторами с помощью USB-UART адаптера.

## 🛠 Что понадобится
1. USB-TTL (UART) адаптер (на базе CH340, CP2102, FTDI или аналогичный).
2. Программа STM32CubeProgrammer (официальная утилита от STMicroelectronics).
3. Соединительные провода Dupont.

---

## Шаг 1: Подключение адаптера к плате Clouds

Переведите микроконтроллер STM32F405 в режим встроенного UART-загрузчика (Bootloader). Для этого после подачи питания из еврорэк-кейса необходимо замкнуть контакт BOOT0 на +3.3V. Для этого, удерживая кнопку SYSBOOT необходимо нажать кнопку RESET. 

Схема подключения USB-TTL адаптера к плате Clouds (разъем SWD/UART):

GND --> GND - Общая земля
TX --> (Transmit) RX
RX --> (Receive) TX

## Шаг 2: Настройка программы STM32CubeProgrammer

1. Подключите USB-TTL адаптер к компьютеру.
2. Запустите STM32CubeProgrammer.
3. В правом верхнем углу в выпадающем меню выберите тип подключения UART.
4. В настройках ниже укажите:
   * Port: Выберите COM-порт вашего адаптера (можно проверить в Диспетчере устройств Windows).
   * Baudrate: `115200` (стабильная скорость для UART-загрузчика).
   * Parity: `Even` (Четный — это обязательное требование загрузчика STM32).
5. Нажмите кнопку Connect. Если подключение прошло успешно, в логе снизу появится информация о процессоре STM32F405.

---

## 💾 Шаг 3: Процесс заливки прошивки

1. Перейдите на вкладку **Erasing & Programming** (иконка с зеленой стрелкой и памятью слева).
2. В поле **File path** нажмите *Browse* и выберите файл прошивки под два кварца: `clouds_Parasites_V3.hex`.
3. Рекомендуется поставить галочку **Verify programming** для проверки целостности данных после записи.
4. Нажмите синюю кнопку **Start Programming** и дождитесь окончания процесса (заполнится зеленая шкала).

---

## 🔄 Шаг 4: Запуск модуля

1. Нажмите кнопку **Disconnect** в программе и отключите USB-адаптер от компьютера.
2. Отключите провода адаптера от платы.
3. Включите питание Eurorack-кейса. Обязательно проведите процедуру калибровки модуля.
4. После индикации об успешной калибровки модуль готов к работе!
